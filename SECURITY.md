# Security policy

Please do not disclose a suspected vulnerability, exploit details, credentials,
license keys, private package URLs, customer logs or personal data in a public
issue.

Use the support/contact path on the canonical
[Custom Performance Cache product page](https://cottoncloud.sk/pluginy/custom-performance-cache/)
and include only the minimum information required to reproduce the issue.

Useful non-sensitive context includes:

- affected product version;
- WordPress and PHP versions;
- hosting/cache layers involved;
- whether the issue affects anonymous or authenticated requests;
- sanitized reproduction steps;
- expected and observed behavior.

Do not send a production database, authentication cookie, API key or a complete
customer log. CottonCloud will coordinate a private channel when additional
evidence is necessary.
